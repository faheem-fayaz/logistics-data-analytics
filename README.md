# Logistics Data Analytics Internship

## Project Overview

This repository contains my four-week Logistics Data Analytics internship
submission. The project demonstrates an end-to-end data analytics workflow
covering strategic planning, data preparation, exploratory analysis,
predictive modeling, and operational optimization.

## Business Problem

The project focuses on a regional e-commerce logistics operation where the
main objectives are:

- Reduce late deliveries
- Improve transportation efficiency
- Monitor logistics performance
- Identify operational bottlenecks
- Support better resource allocation

## Dataset

The practical demonstration uses a reproducible synthetic logistics dataset
containing 1,500 shipment records.

The dataset includes operational variables such as:

- Order date
- Region
- Shipping mode
- Product category
- Shipment volume
- Distance
- Weather risk
- Traffic index
- Warehouse load
- Scheduled delivery days
- Actual delivery days
- Delivery delay
- Transportation cost
- Inventory availability

A public DataCo Smart Supply Chain dataset was used as a reference for the
type of logistics fields and analytical structure used in the project.

## Machine Learning

Two regression approaches were evaluated:

1. Linear Regression — used as a transparent baseline.
2. Random Forest Regression — used to model non-linear relationships.

The models were evaluated using:

- Mean Absolute Error (MAE)
- Root Mean Squared Error (RMSE)
- R² Score

## Optimization

A linear programming model was developed to allocate shipment volume across
different transport modes while considering:

- Transportation cost
- Transport capacity
- Expected late-delivery risk
- Service-level constraints

The optimization demonstrates how predictive analytics can be extended into
prescriptive decision-making.
